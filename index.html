Gendy Drone

Xenakis-style stochastic oscillator, the same as Gendy1.ar(1,1,1,1,[40,40],[40,40],0.5,0.5) in SuperCollider. Sliders and number boxes set goal values. The grey figure on each row is the value playing now. Press Execute transition to glide everything from now to goal. Use headphones or a larger speaker.
